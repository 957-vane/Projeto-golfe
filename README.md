# ⛳ Projeto Monitorização de Campos de Golfe
SmartSoil data platform for weather, soil, microbiology and vegetation analytics using PostgreSQL, Python, and Superset

# Objective
The goal of this project is to build an analytical database in PostgreSQL, populated by Python-based ETL processes, to support data exploration and visualization in Superset.

# Technology stack
•	Python
•	PostgreSQL
•	Superset
